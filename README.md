🦊 Fox Fun Facts
O mini-aplicație web interactivă și adorabilă care oferă utilizatorilor imagini cu vulpi, curiozități fascinante și o fișă tehnică pentru diferite specii de vulpi.

✨ Caracteristici
Imagini Aleatorii: Preluare în timp real de fotografii cu vulpi folosind RandomFox API.

Curiozități Dinamice: O listă selectată de "Fun Facts" care se schimbă la fiecare generare.

Fișă Tehnică: Tabel informativ care identifică specia, talia, habitatul și tipul de activitate al vulpii.

Design Modern: Interfață tip "Card" cu colțuri rotunjite, efecte de umbră și un fundal jucăuș decorat cu stickere (emoji-uri).

Experiență Fluidă: Include un loader vizual și mecanism de pre-încărcare a imaginii pentru a evita salturile vizuale pe ecran.

🛠️ Tehnologii Utilizate
HTML5: Structură semantică.

CSS3: * Flexbox pentru centrare și aliniere.

Variabile CSS pentru culori.

Fundal generat prin date SVG.

Design adaptiv (Responsive).

JavaScript (Vanilla): * Fetch API pentru preluarea datelor asincrone.

Manipulare DOM.

Logică pentru corelarea speciilor.
